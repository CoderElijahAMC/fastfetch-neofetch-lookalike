# fastfetch-neofetch-lookalike
A little script to make fastfetch look like neofetch.
Simply run this script to download the [official fastfetch configuration file](https://github.com/fastfetch-cli/fastfetch/blob/dev/presets/neofetch.jsonc) that makes it look like neofetch.
You can download and run this script, or run it simply by copying and pasting the following into your terminal:
```
curl -sL https://raw.githubusercontent.com/CoderElijahAMC/fastfetch-neofetch-lookalike/refs/heads/main/neofastfetch.sh | bash
```
